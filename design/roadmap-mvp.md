# Roadmap: Система управления маршрутами — MVP

**Версия:** 1.0
**Дата:** Февраль 2026
**Спецификация:** [SPEC_маршруты_v1.md](/SPEC_маршруты_v1.md)
**Дизайн-система:** [design-system/kover/MASTER.md](/design-system/kover/MASTER.md)

---

## Обзор

Веб-приложение для управления маршрутами курьера сервиса аренды грязезащитных ковриков. Заменяет Excel-файл «Илья_новый.xls» (143 клиента, 5 дней, ~280 точек/неделю).

**Пользователи:**
- Админ (владелец бизнеса) — управляет базой и маршрутами через веб-интерфейс
- Илья (курьер, 55 лет) — получает печатный маршрутный лист

**Формат:** React SPA, localStorage, без сервера, без логинов.

## UI/UX Design System

> Полная спецификация: [design-system/kover/MASTER.md](/design-system/kover/MASTER.md)

### Стиль: Minimalism + Flat Design

Операционный дашборд, замена Excel. Нужна ясность, не декорации.

- **WCAG AAA**, performance: excellent, complexity: low
- Без градиентов, glow-эффектов, орнаментов
- Transitions: 150–200ms ease
- Dark mode first, light mode supported

### Layout: Sidebar Dashboard

```
┌──────────┬──────────────────────────────────────┐
│          │  Top Bar: Day Switcher (ПН–ПТ)       │
│ Sidebar  │──────────────────────────────────────│
│          │  Summary Cards (точки, коврики, м²)  │
│ - Маршрут│──────────────────────────────────────│
│ - Клиенты│  Main Content (список / таблица)     │
│ - Импорт │                                      │
└──────────┴──────────────────────────────────────┘
```

- Sidebar: collapsible, на мобильных — bottom tabs
- Top bar: переключатель дней, поиск, кнопка печати

### Палитра (Dark Mode Primary)

| Роль | Tailwind | Hex |
|------|----------|-----|
| Фон страницы | `slate-950` | `#020617` |
| Карточки, sidebar | `slate-900` | `#0F172A` |
| Hover, active | `slate-800` | `#1E293B` |
| Primary (дни, ссылки) | `blue-600` | `#2563EB` |
| CTA / Warning | `orange-500` | `#F97316` |
| Success (выполнено) | `green-500` | `#22C55E` |
| Destructive (удалить) | `red-500` | `#EF4444` |
| Текст основной | `slate-50` | `#F8FAFC` |
| Текст вторичный | `slate-400` | `#94A3B8` |


### Типографика: Inter

- **Шрифт:** Inter (дефолт Shadcn/ui, уже включён)
- **Не** Fira Code — моноширинный тяжело читать курьеру 55 лет
- Body: 16px min, заголовки: 18–24px, `tabular-nums` для всех чисел

| Элемент | Tailwind |
|---------|----------|
| Заголовок страницы | `text-2xl font-bold` |
| Заголовок секции | `text-lg font-semibold` |
| Основной текст | `text-base` (16px) |
| Числа (коврики, м²) | `text-base font-semibold tabular-nums` |
| Метки, подсказки | `text-sm font-medium` |
| Бейджи | `text-xs font-semibold` |

### Accessibility (курьер, 55 лет)

- Touch targets: **44x44px** minimum для всех кнопок
- Контраст: **7:1** для обычного текста, **4.5:1** для крупного
- Focus rings: `ring-2 ring-blue-500 ring-offset-2`
- `prefers-reduced-motion` — отключение анимаций
- Без цвет-only индикаторов — всегда иконка + текст
- `aria-label` на всех icon-only кнопках

### Печать (маршрутный лист)

- `@media print`: скрыть sidebar, навигацию, кнопки, поиск
- Шрифт: системный serif (Times New Roman), **14pt** body, **18pt+** заголовки
- Ч/Б, A4 portrait, margins 15mm
- Чекбокс: пустой квадрат **15x15mm** для ручных отметок

### Иконки: Lucide React

- Размер: `w-5 h-5` (20px), в бейджах `w-4 h-4`
- **Без эмодзи** — только SVG из Lucide
- Route: `MapPin`, `Truck`, `Navigation`
- Actions: `Plus`, `Trash2`, `GripVertical`, `Printer`
- Status: `Check`, `Circle`, `AlertTriangle`

### Компоненты (Shadcn/ui)

| Компонент | Спецификация |
|-----------|-------------|
| Day Switcher | 5 pill-кнопок, active: `bg-blue-600`, badge с кол-вом точек |
| Route Stop Card | `border-l-3 border-l-blue-500`, `p-3`, hover: `bg-slate-800` |
| Summary Cards | Ряд метрик: иконка + значение (`text-2xl bold`) + подпись |
| Data Table | Rows 48px min, sticky header, `overflow-x-auto` на мобильных |
| Modals | `bg-black/50 backdrop-blur-sm`, max-w 500px, close 44x44px |
| Forms | Input height 44px, label сверху, autosave → toast 2 сек |

### Anti-Patterns

- Без inline styles → только Tailwind
- Без glow/neon → чистый flat
- Без scale на hover → вызывает layout shift
- Без шрифта < 14px → курьер не прочитает
- Без nested scroll → один скролл на всё
- Без auto-play анимаций

## UX-принципы (сквозные)

- **Автосохранение** — никаких кнопок «Сохранить». Тост «Сохранено» на 2 сек
- **Подтверждение деструктивных действий** — удаление клиента, удаление из маршрута
- **Шрифт** — 16px основной, 18px+ заголовки (курьер 55 лет)
- **Максимум 2 клика** до любой функции
- **Dark mode first** (конвенция проекта)
- **originalName** в маршруте и печати — привычный формат из Excel
- **tabular-nums** — для всех числовых данных (выравнивание в таблицах)
