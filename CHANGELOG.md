# Changelog

All notable changes to Kover will be documented in this file.

## v1.1.0 (2026-02-23)

### Новое

- Все данные теперь хранятся только в облаке Supabase — localStorage полностью убран
- Прибыльность по клиенту — видно доход и расход на странице статистики (#406)
- Страница техработ — можно показать пользователям заглушку на время обновлений (#423)
- Маршрут выполнен — план и факт теперь различимы, добавлен статус выполнения (#405)
- Сигналы оттока — система предупреждает когда клиент может уйти (#404)
- Инвентарь: collapsible блоки износа и свёрнутая история операций (#416)
- Инвентарь: summary-бар и редизайн карточек размеров (#415)
- Workflow по работе с должниками — долги больше не копятся молча (#403)
- Красные/янтарные карточки клиентов теперь объясняют причину подсветки (#409)
- Водитель видит заметки клиента при обслуживании (#402)

### Исправления

- Индикатор сохранения стал заметнее — toast вместо иконки
- Не дублируется город в запросе геокодирования
- Исправлено ограничение количества замен в день для клиентов с обслуживанием раз в неделю (#412)

### Прочее

- Нововведения переписаны понятным языком (#414)
- Убран auto-release из ship — релиз только по /release
